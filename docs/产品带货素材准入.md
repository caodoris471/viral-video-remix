# 产品带货素材准入

## 采集前确认这次卖什么

同一批先锁定目标商品。有多个 SKU 时分别记录素材与功效依据。记录目标 SKU/规格、产品形态、使用部位或对象、核心功效、用法及必要限制。商品详情页能覆盖这些信息时可直接采用；否则用可辨认的正面包装图、背标或说明书，加用户确认的主推功效补齐。照片负责识别产品，功效、用量、接触时间与适用范围以用户提供的产品资料为依据。开工时主动请用户提供这款商品的透明背景 PNG，或能看清实物、安装或使用动作的实拍片段。视频可发文件或可访问的链接。两种都有时可以一起发。PNG 用于角标，实拍用于对应口播的展示和演示。用户已提供的直接沿用，暂缺的记录待补。需要角标时，透明 PNG 可在导出前补齐。提前记录用户打算放的角落和大概大小；位置未定时，先选择并记录一个能避开主体、字幕和平台互动区的候选区域。

先用「形态/用法 + 部位 + 功效」组合搜索素材。例如确认是刷洗型去水垢凝胶后，可搜「洁厕凝胶 内沿 水垢」及其当地语言对应词。水箱挂瓶、贴花香氛、可替换刷头都另作候选类型，即使同属洁厕品类也不混入。候选标题、标签或爆款互动量只能辅助发现，逐段核对实际画面和用法。

## 每个片段给一个入剪决定

| 决定 | 可用范围 |
|---|---|
| 可入剪 · 自家产品 | 用户提供或确认属于目标 SKU 且可用的实拍、包装、商品图与演示。效果画面应有该 SKU 的真实证据。 |
| 可入剪 · 通用画面 | 与主推功效相关的场景、痛点特写和通用动作，如水垢、内沿脏污、清水冲洗。检查全段无可识别的他品、品牌或独特装置。画面只作场景说明，剪接与字幕不暗示它是自家商品的实测效果。 |
| 仅结构参考 | 带同类商品或他品演示的段落可分析钩子、论证顺序和节奏，原镜头不进入成片。 |
| 排除 | 他品露出、品牌名、包装、带辨识度的瓶型/刷头/贴花/挂件、第三方商品上手或效果演示、购物贴纸和原口播推品。功效、用法或归因存疑的段落也先排除。去掉 Logo 或盖上自家 PNG 不能使他品演示变成可用素材。 |

按原片固定编号和实际秒段记用途、核对到的形态/用法/功效、第三方露出、准入结论和原因。一个原片若部分通过，只提取连续合格的秒段，保留与原片时间的映射。通过准入的裁片单独存放，配镜头仅从该目录扫描。每个审核通过的候选窗在 work/tags.json 加 `产品入剪已复核`，补采和换窗后重新审核。指定窗、另行插入的静态图和自定义 EDL 也必须经过同样的检查。

写脚本时把每句口播对应到准入片段。自家使用演示、前后对比、除菌率、持续时间等必须有用户提供的对应证据。只缺该类镜头时先补自家实拍，或把句子改为有素材支撑的场景说明。用户明确要求产品 PNG 角标时，使用真正透明的自家商品 PNG 叠在指定角落。主画面按口播切到对应实拍动作，商品图保持角标尺寸。在项目配置或单条分镜填写「产品角标」的「文件」「宽」「右距」「底距」。文件用绝对路径，尺寸用画布像素。`match.py` 将设置带入 EDL，自定义 EDL 也可以直接填写。预览首帧至末帧实际显示，剪映使用独立角标轨。用户只要求预留位置时再交留位版。

导出后完整复看，每段检查画面边缘、背景、过渡帧、字幕、原声及口播，确认他品零露出、零推介，口播所称功效有来源，PNG 位不挡主体、字幕和互动区域。存在疑点时修正对应镜头或文案再交付。
