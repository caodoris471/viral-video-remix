爆款视频自动抓取 → 混剪成新视频：安装与配置

仓库：github.com/caodoris471/viral-video-remix　·　Windows 10/11　·　Codex / Claude Code 都能用。流程说明见 docs/流程SOP.html。

第 1 步　打开 Codex 或 Claude Code，把下面这段话原样发给它：

帮我安装这个 skill：https://github.com/caodoris471/viral-video-remix
把它 git clone 到你的 skills 目录（Codex 是 ~/.codex/skills，Claude Code 是 ~/.claude/skills），文件夹名 爆款视频混剪-viral-video-remix；然后运行里面的 一键安装.ps1，装完告诉我哪些通过、哪些要我手动处理。
采集对标用的 skill 也一起装：https://github.com/caodoris471/blogger-video-pipeline

第 2 步　装完后，开新对话，说一句：

用 viral-video-remix 帮我做一批混剪

它会先问你：目标国家/语言、AI 配音还是真人配音（AI 只问男声/女声）、这批出几条（对应几个爆款结构）、每条大概想混剪成多长（如一分钟上下）、品类和素材在哪。已有答案直接沿用；每条时长和整批总时长分开记录，答完再往下跑。

AI 会自动处理：装 git / Python / ffmpeg（缺的话用 winget）、装依赖、装浏览器驱动、下载 Mixkit 音效配乐、检查字体和剪映。你只需要在它提示时：装剪映专业版并打开一次；采集平台时扫码登录。

第 1 步 装 git、Python 3.10+、ffmpeg

打开 PowerShell，逐行运行（已装的会提示已安装，跳过即可）： 
winget install -e --id Git.Git
winget install -e --id Python.Python.3.12
winget install -e --id Gyan.FFmpeg
装完关掉 PowerShell 再开一个，验证：git --version、python --version、ffmpeg -version。没有 winget（老版 Win10）：分别去 git-scm.com、python.org（安装时勾选 Add to PATH）、gyan.dev/ffmpeg/builds 下载。

第 2 步 下载 skill

Codex 用户： 
git clone https://github.com/caodoris471/viral-video-remix "$HOME\.codex\skills\爆款视频混剪-viral-video-remix"
Claude Code 用户把路径换成 $HOME\.claude\skills\爆款视频混剪-viral-video-remix。国内连不上 GitHub：先开代理，或在 PowerShell 里 $env:https_proxy="http://127.0.0.1:你的代理端口"。以后更新：进这个文件夹运行 git pull。

第 3 步 运行安装脚本

cd "$HOME\.codex\skills\爆款视频混剪-viral-video-remix"
powershell -ExecutionPolicy Bypass -File .\一键安装.ps1
它会走清华镜像装这些 Python 包：
包用在哪
opencv-python, numpy切点检测、裁切、运动量、亮度
rapidocr_onnxruntime识别烧录字幕、提供避字裁切建议；不具备字幕擦除修复能力
faster-whisper口播逐字/逐词时间戳、爆款转写（本地；首次运行下载约 500MB 模型）
pyJianYingDraft 0.3.1生成剪映草稿
edge-tts ≥7.3.1免费 AI 配音，16 种语言（低于 7.3 会报 403）
playwright采集 skill 用的浏览器

第 4 步 采集 skill（找对标、下原片）

git clone https://github.com/caodoris471/blogger-video-pipeline "$HOME\.codex\skills\blogger-video-pipeline"
支持抖音、小红书、视频号、B站、快手、YouTube、TikTok、Instagram。各平台登录方法见它的 README。登录状态文件夹含你的账号凭证，不要分享。
TikTok 原片默认接入 TikSave 网页服务，无需安装额外插件。使用会话提供的浏览器工具，沿用用户指定浏览器；下载后由 tools/tiktok_assets.py 登记、抽帧并记录人工水印复核。它不自动擦除英文烧录字幕。网页入口可访问不等于下载实测成功；遇到浏览器停止或网站验证需记录真实状态。操作见 TikSave 接入说明。

第 5 步 剪映专业版和字体

装剪映专业版后打开一次，生成草稿索引。草稿目录改过位置的，安装草稿时加 --draft-root 你的草稿目录。
中文花字预览用「汉仪雅酷黑 95W」（可选，右键字体 → 为当前用户安装）；用别的字体：setx MIX_KWFONT "C:/Windows/Fonts/你的字体.ttf"。外语自动用系统自带字体（Segoe UI Black / Yu Gothic / Malgun Gothic / Leelawadee）。剪映草稿用剪映自带字体，不受影响。

第 6 步 音效和配乐（自动）

安装脚本会自动从 Mixkit 官网下载 10 个音效 + 4 首配乐到 音效库\（免费可商用）。没下成功就单独跑 python tools\get_sfx.py。想换音效：从 mixkit.co 下载放进去，改项目 config 的 音效/配乐 文件名。

第 7 步 新建项目

xcopy /E /I projects\_模板 projects\北欧风服装店
