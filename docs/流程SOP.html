实拍素材 + 口播 混剪 SOP

目标：一批 20–40 秒 9:16 种草/带货短视频（每条对应一个爆款结构，方便测试哪种结构有效），真人口播或 16 种语言的 AI 口播，产出预览 MP4 + 剪映草稿 + 批次清单。换品类/换国家只改项目配置，工具不改。

开工前先定 4 件事

1目标国家/语言：zh / en / en-GB / ja / ko / es / pt / fr / de / it / ru / id / ms / vi / fil / th。决定配音、识别、字幕字体、按字还是按词切。
2配音方式：AI 配音 / 真人配音 / 两版。AI 只选男声或女声，自动用该语言最热门的免费音色（中文男=云希，女=晓晓）。
3批次：这批几条成片 = 几个爆款结构 S1…Sn，各自对应哪条对标视频。
4品类和素材：品类名、原片在哪。
0 采集对标→1 爆款拆解→2 扫素材+打标签→3 写文案(对素材)→4 口播→5 分镜→6 配镜头→7 出片→8 自检→9 装进剪映

五条硬规则

1镜头 1.5–4 秒，中位约 2.5 秒（对标节奏 ≈0.35 切/秒）。短了像幻灯片，长了拖。
2只在句间或句内逗号停顿处切，开口前 2 帧。不在词中间切。
3每段先写「画面必须有什么」，裁切后画面里真的有，才能配。
4没有合格镜头就报缺镜头、停下补素材，不拿无关镜头凑。同一原镜头只用一次。
5优先动态镜头，静态最多 5 个且加 12% 推近。转场全片 ≤3 个，速度一律 1.0。

节点详情

0采集对标 + 下载原片

工具skill blogger-video-pipeline（github.com/caodoris471/blogger-video-pipeline）：抖音 / 小红书 / 视频号 / B站 / 快手 / YouTube / TikTok / Instagram 都能抓，带互动数据筛选和下载
输入目标平台 + 品类关键词或博主（如「北欧风服装店探店」）
输出候选清单、互动数据排名、原片 mp4（放进 config 的素材目录）
要点只读不互动。每次 ≤3 个关键词、每词滚 2 次、词间隔 30–45 秒，单条间隔 25–40 秒；遇到 502/空数据/验证码立即停。
优先探店实拍、长镜头、字幕少的；别人剪好的快切合集基本没用。

1爆款拆解

工具transcribe.py（本地 faster-whisper 逐句转写）、ref_compare.py（量切点节奏）
输出每条爆款一个结构编号 S1…Sn（和飞书文档「爆款结构1…n」对应，记下对标链接）：钩子 / 要点数 / 每段秒数 / 语速 / 结尾引导；剪辑节奏指标
要点一批几条成片就拆几条爆款，一条成片只用一个结构，后面才能比较哪个结构好。外语对标加 --lang=en 等。只借结构，不抄文字。

2扫素材 + 打标签

工具scan.py（切点、OCR 避字幕自动 9:16 裁切、宽裁切、运动量、联系表）→ summary.py → 人或 AI 看 work/sheets/*.png 打标签（tag_sheet.py 辅助）
输出work/candidates.json、work/tags.json（如 {"A03":["全景_餐厅","暖光"]}）、work/file_ids.json（素材固定编号）
要点只标裁切后清楚看得见的。口播人像、效果图、画中画、后期标注要标出来，匹配时自动排除。重扫后窗号变了用 remap_tags.py 搬标签。4K 素材先缩到 1080p 再入库，否则可能爆内存。

3写文案（先对素材）

工具LLM 写稿 + overlap_check.py（和参考稿 4 字重合率 >30% 或连续相同 ≥12 字 → 改写）
输出每个结构一份 inputs/文稿_S1.txt…，一句一行
要点每句先写「画面必须有什么」，对照 tags.json：每类至少 2 个 ≥4 秒可用窗。不够就补素材或改句子。素材够了再录音，录完就改不了。口语化，别写成文言文。

4口播：真人版 / AI 版

真人录音放 inputs/ → voice_prep.py（对齐文稿、剪口误、压停顿、出逐字时间戳）→ 有重录用 voice_splice.py 2=第二句.m4a → voice_speed.py … 1.25（不变调提速 + 降噪 + 压缩）
AItts_edge.py 文稿_S1.txt S1.mp3 --lang=en --gender=女（免费，16 种语言，按性别自动选最热门音色）→ voice_prep.py … --lang=en。英语等按词对齐，中文/日文/泰文按字。ElevenLabs（tts_elevenlabs.py，key 放环境变量）可选。
输出口播_精剪.wav + timestamps.json
排查voice_inspect.py <目录> <句号> 看某句逐字时间和音量，找没压掉的停顿

5写分镜 分镜_<版本>.json

工具plan_beats.py 按口播时间建议分段 → 手填 → coverage.py 覆盖检查
每段字段句 / 起字 / 要点 / 必需(1–2 标签) / 优先 / 关键词(词 必须和录音一致、显示、音效) / 出转场(闪白·模糊·叠化)
要点文件名带结构号：分镜_S1_AI.json，里面写 爆款结构、对标链接，草稿名 品类_S1_AI_V1。英语等语言「起字」=第几个词。真人版、AI 版语速不同，各写一份。同一要点连 2–3 个同类镜头。大字和音效只放开头、每个要点标题、结尾提问。coverage 里合格数 0 的段先补素材。

6配镜头 + 调色

工具match.py <项目> 分镜.json → grade.py <项目> EDL.json；预演模式缺镜头插占位卡
输出work/EDL_<版本>.json（含降级记录、调色）
逻辑可选最少的段先配；打分 = 优先命中×3 + 运动量 + 清晰度；同要点优先同一原片；找不到先降级再报缺。grade 把亮度往全片中位拉一半。

7出片

工具render.py <项目> EDL.json（ffmpeg 预览 + pyJianYingDraft 剪映草稿）
输出output/<版本>/：*_预览.mp4、*_预览_VSCode可播.mp4、剪映草稿/、素材/、安装到剪映.cmd
画面1080×1920，上下用同画面模糊填充；大字 5 种样式随机（花字/砸字/宋体/重点/竖排），开头固定花字（黄字深棕描边，汉仪雅酷黑 95W），逐字弹跳；草稿里用剪映原生字体和动画（波浪弹入/放大震动等），可直接改
声音口播 + 配乐 -14dB（人声时压低 6dB）+ 少量音效（pop/whoosh/wood/chime/shutter，Mixkit 免费库）

8自检

工具qa.py <项目> <版本>、ref_compare.py（和对标比节奏）、shot_stats.py（查相邻镜头亮度/色温跳变）
检查镜头时长、切点位置、必需标签、窗重复、越界、总时长帧数；生成 检查_逐段对照.png。全部通过 + 对照图逐格看过，才交给人审。

9装进剪映

操作先完全退出剪映（托盘也退） → 双击版本目录里 安装到剪映.cmd → 打开剪映，本地草稿里点开微调
坑剪映开着时装，退出时它会覆盖草稿列表，新草稿消失。安装器会自动备份 root_meta_info.json。

批次清单（测试爆款结构）

工具batch_list.py <项目>
输出批次清单.csv：每条成片一行，爆款结构 / 对标链接 / 语言 / 时长 / 文案 / 成片路径，后面留空列：发布平台、链接、播放、完播率、点赞、评论、收藏、转发、结论。可整表导入飞书多维表，按结构对比数据。

换新品类/国家要改的

config语言、名称、素材目录、音效目录、标签词表（如服装：上身全身 / 面料特写 / 细节_领口 / 场景_通勤）、排除标签
文稿新写，先对素材
分镜真人、AI 各一份，标签用新词表
不用改tools/ 全部、规则参数（除非品类节奏明显不同）
已知局限：OCR 会把真实招牌字当字幕避开，裁切窗变小；画中画靠人工标；预览是 ffmpeg 模拟，字体动画以剪映为准；Windows 下 OpenCV 读写中文路径要用 imencode/imdecode；音效配乐商用前核对许可。
