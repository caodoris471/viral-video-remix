# 采集入口与批量续作

## 主页加产品图如何启动

用户给账号主页和产品图，表示“从这个账号找参考，卖图里的商品”。先识别商品、登记来源、浏览指定主页，不要求用户再想一组搜索关键词。补问只针对尚未明确的数量、每条大概时长、语言/配音、指标门槛、商品功效/用法和角标位置；会话中已有答案直接沿用。已允许先做预览时，先交一条，确认后按该效果扩展。

产品图用于识别商品和做角标。清晰白底 JPG/PNG 也可接收，导出前再抠成透明 PNG，检查边缘、瓶型、标签文字。图片本身不足以证明除菌率、免冲洗、食品接触安全或等待时间，资料缺失时补问；不从参考竞品的旁白借用功效。

用户没有自家演示且明确让用采集场景时，可选通过产品准入的通用脏污、检查与擦拭动作，商品介绍时仍保持动态场景和角落 PNG。没有自家实测依据时，不用旁白或剪接声称画面证明该 SKU 的效果。详情见[产品带货素材准入](产品带货素材准入.md)。

## 两个独立选择

| 维度 | 选项 | 决定什么 |
|---|---|---|
| 采集入口 | 账号主页 / 关键词 / 指定视频或本地素材 | 到哪里找参考和候选素材 |
| 任务类型 | 产品类 / 非产品类 | 怎么判定画面、功效和文案是否匹配 |

账号主页可以用于产品片，也可以用于装修、旅游主题。产品类也可以通过关键词跨账号采集；不能把两维合并成互斥模式。

### 指定账号

- 只采用户指定账号的作品；其他账号需另有授权，不因候选不足自动扩大范围。
- 先按主题筛选，再核实用户要求的指标。`播放量 > 1000` 不等于 `播放量 >= 1000`，也不等于点赞超过1000；用数字比较，缺失记未知，主页置顶不代表达标。
- 每条保留账号、平台视频 ID（字符串）、固定素材编号、原链接、指标值、采集时间和证据。热度是采集时快照。
- 记录实际扫描条数、翻页是否结束及停止原因。只读到部分作品时不能写“全账号抓完”或“只有这些视频”。
- 达到热度门槛仍须核对商品形态、使用部位和可用秒段，不把账号里的所有产品或功效混用。

### 关键词

- 记录平台、关键词、指标门槛和实际搜索范围。产品类用“产品形态/用法 + 使用部位 + 已确认功效”细化检索。
- 允许跨账号发现候选；仍须逐段商品准入。非产品类按风格、地点、场景筛选。
- 没有命中的合格素材时报告缺口；不靠更换无关商品或循环镜头完成数量。

`config.json` 中的 `采集` 是任务记录，交给采集工具/浏览器执行，不是新增爬虫接口。平台登录、浏览器和下载工具沿用用户选择；TikTok 下载按 TikSave 文档核对实际文件与烧录标记。

## 预览确认后的续作

1. 保留已确认成片，延续其语言、配音、角标位置、动态要求和大致时长；继续原编号。用户说“再出10条”时记录新增10条与原有数量。
2. 在配音前写批次策划：结构号、切入点、主参考、原片功能→本条改编顺序、脚本、对应镜头。每条有不同开场和叙述安排，不能只换标题、旁白或随机打乱同一段时间线。
3. 参考原片数与成片数分别记录。两条参考改写成十条时，标清十个变体及同一来源的关联；不虚构十条新对标。跨成片可复用已通过的镜头，同一成片不循环同一原镜头。
4. “约一分钟”是规划时长，不固定为某个秒数。明显偏离时复核信息量并说明实测长度，不把本次40余秒写成后续默认时长，不用定格、长空镜或大幅变速凑够一分钟。
5. 用户要求全动态时，`画面模式` 填 `全动态`。配镜头将静态名额设为0，拒绝整屏图片。主画面必须来自连续视频，固定的商品角标单独成轨。元数据检查不能识别所有已烘焙定格，导出后还要动态检测/复看。
6. 字幕用实际字体测宽，按词时间戳分屏。导出后检查首尾、逐镜中点和转场边缘，核对竞品、残字、字幕越界与 PNG 遮挡；剪映素材引用完整。

全动态片可用 FFmpeg 辅助检查长时间无变化的画面，例如 `-vf "freezedetect=n=-50dB:d=0.6"`。这是诊断线索，自然停顿和压缩也可能影响结果；发现区间须复看，不能单靠“文件是MP4”就认定无定格，也不能把角标当成静态主画面。

## 交付与进度

多条交付提供单一预览入口、各条 MP4、剪映草稿及素材、字幕、独立文案和中外文对照、逐镜来源与批次 CSV。核对入口链接指向当前终稿、文件可读，不并列多个无说明旧版。

进度分别报导出数与验收数。任务中断后核对进程和文件状态，再继续未完成部分；不要把“已启动10条渲染”报告成“10条已完成”。本地工程遵从用户的项目位置与清理规则，发布仓库不带入用户素材、商品图、账号私密数据或项目临时文件。
