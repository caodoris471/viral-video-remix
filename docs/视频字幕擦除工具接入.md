# 视频字幕擦除工具接入

需要去除烧录在画面里的原字幕、保留原构图时读取。这里记录真实工具入口和接入验收流程，不代表工具已安装或本机已试片通过。

## 复用已有运行环境

优先使用本机可用的独立解释器、适配脚本和模型。实际运行时记录命令、版本和试片结果。换机器或环境后，先用代表片段重验。

每种素材来源、每种字幕布局都要先检查完整画面和代表试片。字幕可能在画面下部而非最底边；选区要覆盖两行文字、描边和高亮色块，不能把某一条成功试片的ROI直接套给所有来源。完整画面的实物包装字、背景招牌与原字幕分开判断。

## 已核实的外部工具

外部工具 [YaoFANGUK/video-subtitle-remover（VSR）](https://github.com/YaoFANGUK/video-subtitle-remover) 通过图像/视频修复处理硬字幕；支持本地运行、Windows和命令行，提供STTN、LaMa等模式。与本包的OCR避字裁切不是同一种处理。

已核实入口：

- [命令行实现](https://github.com/YaoFANGUK/video-subtitle-remover/blob/main/backend/main.py)：从仓库目录运行 `python backend/main.py`。
- [实际参数解析](https://github.com/YaoFANGUK/video-subtitle-remover/blob/main/backend/tools/args_handler.py)：`--input/-i`、`--output/-o`；`--subtitle-area-coords/-c`按像素传入`YMIN YMAX XMIN XMAX`，可重复设置多个区域；`--inpaint-mode`选择实际版本支持的模式。始终明确传输入、输出和已审核的字幕区域，不依赖默认输出或默认全屏选区。
- [配置与显存参数](https://github.com/YaoFANGUK/video-subtitle-remover/blob/main/backend/config.py)：ProPainter比其他模式更吃显存，不默认选择最高资源消耗的算法。
- [官方安装说明](https://github.com/YaoFANGUK/video-subtitle-remover#源码使用说明)：按实际设备、驱动与Python版本选择依赖；不要照抄未经本机验证的CUDA安装组合。

备选可研究 [VideoWipe](https://github.com/KKenny0/videowipe)，它提供先审查检测结果再修复的CLI流程；若改用它，另核对对应版本的参数和依赖，不混用VSR参数。

## 接入时做什么

1. 先查本机是否已有VSR或等效修复工具、可运行的独立Python环境和模型；检查实际命令帮助与模型载入结果。记录工具来源、版本/提交、运行目录、解释器和模型路径。
2. 新增运行环境、源码、模型及可指定缓存放用户的工程盘，可复用工具独立于单条视频项目存放。Skill目录只留指令与轻量辅助代码。使用隔离环境，避免覆盖现有混剪工具链的依赖。
3. 先取当前原片中2–4秒的代表片段，保持分辨率与构图，保存原片、去字掩膜和修复片。圈定真正的原字幕区域，排除产品包装文字及需要保留的画面内容。
4. 选择能在当前硬件下运行的模式试片；不要仅凭检测到显卡就承诺速度或效果。模型载入、处理完成、输出可解码都要实际验证。新模型或算法的使用条件按所用版本核对。
5. 逐镜查看残字、阴影边缘、闪烁、拖影及主体形变，并核对宽高、帧率、帧数和音画时长。修复不得改变作为产品演示证据的污渍、材质或产品结构。存在明显伪影时换参数或素材，不用裁切/模糊把失败修复称为成功。
6. 试片通过后再清理需要混剪的片段，保留固定素材编号、原片起止与清理片路径映射，回到主流程扫描、打标签、配镜头。清理片保留原片构图时，不要自动套上宽裁切和上下模糊。

## 对外说明状态

- **找到工具**：已核对仓库、功能及入口，尚未证明本机可运行。
- **安装完成**：依赖和所需模型可载入，仍未证明素材修复质量。
- **试片通过**：当前片段完成修复、媒体检查及逐镜目检；只对已验收的素材这样标记。
- **已接入混剪流程**：后续扫描与渲染实际使用已验收的清理片，并保留来源映射。

不要把“添加了本说明”“成功运行--help”或“GitHub有演示视频”说成已完成视频去字幕。
